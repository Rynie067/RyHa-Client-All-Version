# RyHa Client — All Versions

RyHa Client sürümlerinin resmi indirme arşivi.

## İndirme

Yayınlanmış sürümleri görmek ve indirmek için:

**[Tüm sürümleri görüntüle →](https://github.com/Rynie067/RyHa-Client-All-Version/releases)**

En güncel kararlı sürüm GitHub Releases bölümünde **Latest** etiketiyle gösterilir. Deneme sürümleri ayrıca **Pre-release** olarak işaretlenir.

## Sürüm dosyaları

Her sürümün çalıştırılabilir/mod dosyaları ilgili GitHub Release kaydına dosya eki (asset) olarak yüklenecektir. Depodaki otomatik **Source code (zip/tar.gz)** bağlantıları derlenmiş RyHa Client dosyası değildir.

Dosya adlandırma önerisi:

- `RyHa-Client-<version>.jar`
- Gerekliyse ek dosyalar, ne oldukları açıkça belirtilen adlarla.

## Sürüm numaralandırması

- Kararlı sürüm: `v1.0.0`
- Beta: `v1.0.0-beta.1`
- Release adında sürüm numarasını açıkça belirt.

## Sürüm notları

Her yayın açıklamasında mümkünse şunları belirt:

- **Minecraft sürümü**
- **Loader / platform** (ör. Fabric; yalnızca gerçekten destekleniyorsa)
- **Değişiklikler**
- **Düzeltilen hatalar**
- **Bilinen sorunlar**
- **Kurulum notları**

## Dosya doğrulama

Yayınlanan dosyanın SHA-256 özeti, dosya kesinleştikten sonra release notlarına eklenebilir. Doğrulanmamış hash veya uyumluluk bilgisi paylaşmayın.
